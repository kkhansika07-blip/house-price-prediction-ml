# House Price Prediction ML

Predict house prices using linear regression based on features like area, bedrooms, bathrooms, age, and location.

## Dataset
- data/house_prices.csv - Contains house features and prices

## Notebooks
- 
otebooks/house_price_prediction.ipynb - EDA, preprocessing, LinearRegression, evaluation (MAE/RMSE/R2), and visualizations

## Installation
`ash
pip install -r requirements.txt
`

## Usage
Run the notebook in Jupyter/VSCode to explore and predict house prices.
